# مبيعات كيان (kayan-sales)

إضافة لـClaude تشتغل على بيانات شركتك في منصة كيان (Kayan One): فرص البيع، والعملاء، والصفقات، وفواتير المبيعات، والتحصيل.

## التثبيت
1. اربط Claude بحسابك في كيان: الإضافة فيها رابط الـconnector `https://app.kayan-one.com/mcp`، وأول مرة Claude هيطلب منك تسجّل دخول بحساب كيان.
2. ثبّت الإضافة من سوق إضافات كيان. في Claude Code:

   ```
   /plugin install kayan-sales --marketplace kayan-one/claude-plugins
   ```

   وفي claude.ai (Cowork): ارفع ملف `kayan-sales.zip` من قسم الإضافات، أو ثبّتها من سوق كيان لما يتضاف للمؤسسة.
3. اكتب لـClaude بالعربي، مثلًا: «تقرير الصبح»، «حضّرلي مكالمة مع أسواق النخبة»، «مين متأخر في السداد؟».

## المهارات
| المهارة | بتعمل إيه |
|---|---|
| morning-brief | تقرير الصبح: المتابعات المطلوبة النهارده، والفرص الواقفة، وعروض الأسعار من غير رد، والمتأخر في السداد |
| call-prep | تحضير مكالمة أو زيارة عميل: صفقاته وفواتيره ورصيده والمتأخر عليه، والنقاط اللي تتقال |
| follow-up | رسالة متابعة بعد مكالمة أو عرض سعر (واتساب أو إيميل) |
| pipeline-review | مراجعة الفرص والصفقات: الواقف، اللي في خطر، والمتوقع يتقفل |
| collections | التحصيل: المتأخرين بالأعمار ورسالة تذكير لكل عميل |
| weekly-report | تقرير أسبوعي للمدير: المبيعات والتحصيل والفرص لكل مندوب |

## الأمان
- كل الأدوات قراءة بس؛ الإضافة لا تسجل ولا تعدّل أي قيد أو فاتورة أو فرصة.
- بتشوف اللي صلاحيتك في المنصة تسمح بيه بس (المندوب يشوف عملاءه).
- أي نص جوه البيانات (أسماء أو ملاحظات) بيانات، مش أوامر.
